# RobPlay

Браузерный платформер о маленьком храбром роботе. Без зависимостей и сборки:
просто откройте `index.html` в браузере или включите GitHub Pages для репозитория.

## Возможности

- **50 уровней** в пяти мирах: Зелёные земли, Стихии, Хаос, Небесные острова, Кибер-мир
- **5 боссов** — на каждом 10-м уровне: Громобот, Буревестник, Ядро Хаоса, Механический Змей, Омега
- **15 видов врагов**: ходок, прыгун, ёж, таран, турель, летун, летучая мышь, призрак, пила, давилка,
  улитка (панцирь можно пнуть), слизень (делится надвое), паук, гренадёр, ракетница
- **Улучшения**: пять способностей на кнопке Shift / X — рывок, удар-молот, бластер, планер, телепорт —
  у каждой три уровня; пассивные улучшения — доп. прыжки, сердца, магнит, скорость
- **Бонусы на уровнях**: щит, магнит для монет, звезда неуязвимости
- **Магазин скинов** (15 скинов с аксессуарами и следами) и **колесо фортуны** с 3 попытками в день
- **Эффекты карт**: дождь с молниями, снег, песчаная буря, листопад, перья, светлячки, пузыри,
  цифровой дождь, лава и вода в пропастях, анимированные декорации и украшения на блоках
- **Особые карты**: скользкий лёд, пониженная гравитация, темнота
- **Свой набор иконок** вместо эмодзи (`icons.js`) — одинаково рисуется в меню и в игре
- **Языки**: русский и английский
- **Стили меню** в духе разных игр: Неон-сити, Ретро 8-бит, Кубический мир, Мультик
- Музыка для каждого мира, боссов и меню, звуки окружения, шаги, голоса врагов
- Сохранение прогресса, статистика, клавиатура, геймпад и сенсорный экран

## Управление

| Клавиши | Действие |
|---|---|
| ← → / A D | Бег |
| Пробел / W / ↑ | Прыжок (в воздухе — ещё раз) |
| Shift / X | Способность |
| ↓ / S | Спрыгнуть с тонкой платформы |
| Esc / P | Пауза |
| R | Начать уровень заново |
| M | Музыка вкл/выкл |

## Структура

- `index.html`, `style.css` — экраны и оформление (включая стили меню)
- `game.js` — движок: физика, отрисовка, звук, ввод, интерфейс
- `abilities.js` — способности и улучшения
- `enemies.js`, `boss.js` — враги, снаряды, боссы
- `powerups.js` — бонусы
- `fx.js`, `decor.js`, `props.js` — погода, декорации и украшения карт
- `skins.js` — скины робота и его отрисовка
- `menu.js` — анимированные фоны меню для каждого стиля
- `wheel.js` — колесо фортуны
- `icons.js` — набор иконок
- `i18n.js` — переводы интерфейса
- `levels.js` — карты уровней (генерируются `tools/gen_levels.py`)

Чтобы изменить уровни, поправьте `tools/gen_levels.py` и запустите `python3 tools/gen_levels.py`.
